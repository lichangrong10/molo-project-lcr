## 项目简介
molo-project-lcr 是一款基于 Vue3 框架 + Vite 构建工具开发的前端项目，
采用现代化前端工程化架构，支持开发环境热更新调试与生产环境打包构建，
适用于各类 Web 前端应用场景的快速开发与部署。

## 核心目录
src/apis	统一管理接口请求，封装 API 调用逻辑，便于接口维护与复用
src/components	存放通用可复用组件（如按钮、表单、弹窗等），提升页面开发效率
src/router	配置前端路由规则，包括路由跳转、参数传递、路由守卫等
src/stores	管理全局 / 跨组件状态（如用户信息、全局配置等）
src/utils	封装通用工具函数（如时间格式化、数据校验、请求拦截等）
src/views	存放页面级组件，对应路由跳转的各个页面
vite.config.js	配置 Vite 构建规则（如代理、别名、打包优化等）

## 技术栈

### 基础开发框架
Vue 核心框架：采用当下主流的 Vue 前端框架作为核心，依托其组件化、响应式数据绑定特性，实现页面逻辑与 UI 层的解耦，大幅提升代码复用性与可维护性；同时兼容 Vue 最新的组合式 API（Composition API），支持更灵活的代码组织方式，适配复杂业务场景的开发需求。
Vite 构建工具：摒弃传统 Webpack 的打包模式，采用 Vite 作为构建工具，开发阶段基于原生 ES 模块实现极速热更新（HMR），启动速度提升数倍，修改代码后无需等待整体打包，即时反馈开发效果；输出体积更小、性能更优的静态资源。

### 工程化与配套能力
npm 包管理：通过 npm 统一管理项目依赖，依托 package-lock.json 锁定依赖版本，保证多环境开发、部署的依赖一致性，避免版本兼容问题。

模块化目录设计：按「接口（apis）、组件（components）、路由（router）、状态管理（stores）、工具函数（utils）、页面视图（views）」等维度拆分目录，遵循前端工程化最佳实践，代码结构清晰，便于团队协作与后期维护。

## 项目核心亮点
标准化目录架构：按「功能模块 + 职责分层」设计目录结构，符合前端通用的工程化规范，新开发者可快速上手，后期新增功能、迭代维护时代码不混乱。

逻辑抽象复用能力：通过 composables、hooks、utils 等目录封装通用逻辑（如接口请求、数据格式化、业务逻辑），组件与页面可直接复用，降低代码冗余，提升迭代效率。

灵活的状态与路由管理：预留 stores（状态管理）、router 目录，可无缝集成 Pinia/Vuex（状态管理）、Vue Router 等主流插件，适配从简单页面到复杂单页应用（SPA）的扩展需求。

高性能打包输出：生产环境通过 npm run build 打包生成轻量化的静态资源（输出至 dist 目录），资源自动压缩、按需加载，部署后页面加载速度快，用户体验佳。
